# Gestor de Escala

Aplicação web para cadastrar equipes, gerar escalas de trabalho,
validar restrições e exportar para PDF e Excel.

**Status:** em planejamento e desenvolvimento inicial. Projeto de aprendizagem
e portfólio.

**Stack planejada:** React + TypeScript, NestJS, PostgreSQL, Prisma e
OR-Tools (Python).

> As regras trabalhistas aqui implementadas são apoio à escala e não
> substituem análise jurídica.
